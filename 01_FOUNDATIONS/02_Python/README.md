
# Python Programming

## Purpose

This section documents the development of Python programming skills, with an emphasis on problem-solving, automation, data processing, and practical cybersecurity applications.

The objective is to progress from fundamental programming concepts to independently developing reliable Python-based security tools.

## Learning Objectives

### 1. Programming Fundamentals
- Variables and data types.
- Strings and numerical operations.
- Input and output.
- Conditional statements.
- Loops and iteration.

### 2. Data Structures
- Lists and tuples.
- Dictionaries and sets.
- Working with structured data.
- Data manipulation and organisation.

### 3. Functions and Modular Programming
- Defining and calling functions.
- Parameters and return values.
- Modules and imports.
- Writing reusable code.

### 4. Files and Error Handling
- Reading and writing files.
- Processing text files.
- Handling exceptions.
- Working with paths and directories.

### 5. Intermediate Python
- Regular expressions.
- JSON and CSV processing.
- Basic API interaction.
- Debugging and testing.
- Code quality and maintainability.

### 6. Cybersecurity Applications
- Analysing authentication logs.
- Identifying suspicious patterns.
- File integrity monitoring.
- Automating repetitive security tasks.
- Processing security-related data.

## Practical Development

Learning will be reinforced through progressively challenging exercises and original projects.

Each practical record should explain:

- The problem being addressed.
- The approach taken.
- The code and its behaviour.
- Testing and observed results.
- Limitations and possible improvements.

## Development Standards

Code should prioritise readability, reliability, appropriate error handling, and clear documentation.

All security-related development and testing will take place in authorised environments.

## Current Status

Foundational Python study is being established. Progress, exercises, and projects will be documented as learning advances.

---

*Learn deliberately. Build responsibly. Improve continuously.*
