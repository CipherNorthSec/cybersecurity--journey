# Linux Fundamentals

## Purpose

This section documents the development of Linux command-line skills and system knowledge relevant to cybersecurity.

The objective is to understand Linux environments, navigate and manage systems confidently, and develop the practical skills needed for security analysis and investigation.

## Learning Objectives

### 1. Command-Line Fundamentals
- Navigating the filesystem.
- Understanding commands and command options.
- Using paths and directories.
- Creating, copying, moving, and removing files.
- Reading command output.

### 2. Filesystem and Permissions
- Understanding the Linux directory structure.
- Identifying file types.
- Understanding users and groups.
- Reading and modifying file permissions.
- Applying the principle of least privilege.

### 3. Users and Processes
- Managing user accounts.
- Understanding running processes.
- Monitoring system activity.
- Using process-management commands.

### 4. System Administration
- Understanding package management.
- Working with services.
- Reviewing system configuration.
- Understanding environment variables.

### 5. Logs and Security
- Locating and reading system logs.
- Understanding authentication logs.
- Identifying unusual activity.
- Investigating basic security events.

### 6. Shell Scripting
- Understanding shell commands and operators.
- Combining commands.
- Using pipes and redirection.
- Developing basic Bash scripts.
- Automating routine tasks.

## Practical Development

Learning will be reinforced through guided exercises, independent practice, and documented investigations.

Each practical record should explain:

- The objective of the exercise.
- The commands used.
- What each command does.
- The observed output.
- Any errors and how they were resolved.
- Lessons learned.

## Development Standards

All exercises should prioritise understanding, safe system administration, accurate documentation, and responsible security practice.

## Current Status

Linux fundamentals are being established through hands-on practice in Ubuntu using WSL.

Progress and practical exercises will be documented as learning advances.
