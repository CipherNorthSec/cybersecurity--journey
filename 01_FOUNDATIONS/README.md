
# 01 | Cybersecurity Foundations

## Purpose

This section documents the development of the fundamental technical knowledge required for cybersecurity practice.

It establishes the theoretical understanding and practical skills that will support more advanced work across penetration testing, defensive security, digital forensics, and security automation.

## Core Learning Areas

### Python Programming
Developing programming fundamentals, problem-solving skills, scripting techniques, and the ability to build practical security tools.

### Linux
Learning command-line operations, filesystem navigation, permissions, processes, system administration, and security-related log analysis.

### Networking
Understanding network architecture, IP addressing, protocols, ports, routing, DNS, and network traffic.

### Cybersecurity Principles
Studying security fundamentals, authentication, access control, cryptography, vulnerabilities, threats, and risk management.

## Learning Approach

Each learning area will include:

- Structured study and technical notes.
- Practical exercises and laboratory work.
- Knowledge checks and assessments.
- Documented problem-solving.
- Reflections on lessons learned.

## Development Standards

Learning records will prioritise:

- Demonstrated understanding rather than completion alone.
- Accurate technical explanations.
- Reproducible practical exercises.
- Responsible and ethical conduct.
- Continuous improvement.

## Current Status

This section is being established as the foundation for further technical development.

Progress and completed work will be documented as learning advances.
