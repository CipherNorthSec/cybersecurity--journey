# Networking Fundamentals

## Purpose

This section documents the development of networking knowledge and practical skills required for cybersecurity.

The objective is to understand how devices communicate, how networks are structured, how data moves between systems, and how network activity can be analysed from a security perspective.

## Learning Objectives

### 1. Networking Fundamentals
- Understanding computer networks.
- Identifying network types and topologies.
- Understanding clients, servers, and network devices.
- Learning the OSI and TCP/IP models.
- Understanding encapsulation and data transmission.

### 2. IP Addressing and Subnetting
- Understanding IPv4 and IPv6.
- Identifying public and private IP addresses.
- Understanding subnet masks and CIDR notation.
- Learning basic subnetting.
- Understanding default gateways.

### 3. Network Protocols and Services
- Understanding TCP and UDP.
- Learning common network ports.
- Understanding DNS and DHCP.
- Exploring ARP and ICMP.
- Understanding HTTP, HTTPS, SSH, and FTP.

### 4. Routing and Network Infrastructure
- Understanding switches and routers.
- Learning how routing works.
- Exploring local area and wide area networks.
- Understanding firewalls and network segmentation.
- Identifying common network infrastructure components.

### 5. Network Traffic Analysis
- Understanding network packets.
- Learning how to capture network traffic.
- Exploring Wireshark.
- Examining protocol behaviour.
- Identifying unusual network activity.

### 6. Networking Security
- Understanding common network attacks.
- Exploring network reconnaissance.
- Learning about traffic filtering.
- Understanding secure communication.
- Studying network monitoring and defensive controls.

## Practical Development

Knowledge will be reinforced through structured exercises, authorised laboratory environments, packet analysis, and documented investigations.

Each practical record should explain:

- The objective of the exercise.
- The networking concepts involved.
- The commands or tools used.
- The observed results.
- The security implications.
- Lessons learned.

## Development Standards

Networking exercises should prioritise technical accuracy, reproducibility, clear documentation, and responsible use of authorised environments.

## Current Status

Networking fundamentals are being established as a core component of technical development.

Progress, practical exercises, and investigations will be documented as learning advances.
