# Cybersecurity Fundamentals

## Purpose

This section documents the development of the knowledge and practical understanding required to identify, assess, prevent, and respond to cybersecurity threats.

The objective is to develop a strong understanding of security principles, common vulnerabilities, threat actors, defensive controls, and the methods used to protect information systems.

## Learning Objectives

### 1. Core Security Principles
- Understanding the CIA triad: confidentiality, integrity, and availability.
- Exploring authentication and authorisation.
- Understanding accountability and non-repudiation.
- Applying the principle of least privilege.
- Understanding defence in depth.

### 2. Threats and Threat Actors
- Identifying common threat actors.
- Understanding motivations and attack objectives.
- Exploring malware, phishing, and social engineering.
- Understanding insider threats.
- Examining common attack methods and techniques.

### 3. Vulnerabilities and Risk Management
- Understanding vulnerabilities and security weaknesses.
- Learning the fundamentals of vulnerability assessment.
- Understanding threats, likelihood, and impact.
- Exploring risk identification and prioritisation.
- Learning about security policies and risk mitigation.

### 4. Authentication and Access Control
- Understanding authentication factors.
- Exploring multi-factor authentication.
- Understanding role-based access control.
- Learning about password security.
- Examining account management and access reviews.

### 5. Cryptography Fundamentals
- Understanding encryption and decryption.
- Exploring symmetric and asymmetric cryptography.
- Understanding hashing and digital signatures.
- Learning the purpose of certificates and public key infrastructure.
- Understanding secure data transmission and storage.

### 6. Defensive Security
- Understanding security monitoring.
- Exploring firewalls and endpoint protection.
- Learning about intrusion detection and prevention.
- Understanding patch management.
- Exploring backup strategies and incident response.

### 7. Security Frameworks and Standards
- Understanding the purpose of security frameworks.
- Exploring NIST Cybersecurity Framework concepts.
- Learning about security policies and procedures.
- Understanding security awareness and governance.
- Exploring how organisations measure and improve security.

## Practical Development

Learning will be reinforced through practical exercises, authorised laboratories, security investigations, and documented assessments.

Each practical record should explain:

- The security concept being examined.
- The problem or scenario.
- The approach and tools used.
- The observed results.
- The security implications.
- Limitations and lessons learned.

## Development Standards

All cybersecurity activities must be conducted ethically and within authorised environments.

Technical explanations should prioritise accuracy, evidence, reproducibility, and a clear understanding of both defensive and offensive security concepts.

## Current Status

Core cybersecurity principles are being established as a foundation for more advanced technical development.

Progress, practical exercises, and security assessments will be documented as learning advances.
