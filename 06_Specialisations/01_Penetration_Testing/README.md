# Penetration Testing

## Purpose

This section documents the development of penetration testing knowledge and practical skills, with an emphasis on identifying security weaknesses through authorised and controlled testing.

The objective is to understand how vulnerabilities are discovered, assessed, validated, and communicated so that organisations can improve their security.

## Learning Objectives

### 1. Ethical and Legal Foundations
- Understanding the purpose of penetration testing.
- Distinguishing authorised testing from unauthorised activity.
- Understanding scope, rules of engagement, and permissions.
- Learning responsible vulnerability disclosure.
- Understanding professional reporting standards.

### 2. Reconnaissance and Information Gathering
- Understanding passive and active reconnaissance.
- Identifying publicly available information.
- Learning about domains, IP addresses, and network services.
- Understanding attack surfaces.
- Documenting findings responsibly.

### 3. Network Security Assessment
- Understanding network scanning concepts.
- Identifying exposed services in authorised laboratories.
- Learning about common network vulnerabilities.
- Understanding service enumeration.
- Assessing security configurations.

### 4. Web Application Security
- Understanding how web applications operate.
- Learning about HTTP requests and responses.
- Exploring common web application vulnerabilities.
- Understanding input validation and access control.
- Studying the OWASP Top 10.

### 5. Vulnerability Assessment
- Understanding vulnerability identification.
- Learning how to evaluate severity and impact.
- Distinguishing confirmed vulnerabilities from potential findings.
- Understanding false positives.
- Prioritising remediation recommendations.

### 6. Technical Reporting
- Documenting testing methodology.
- Explaining findings clearly.
- Providing reproducible evidence.
- Assessing potential business impact.
- Recommending appropriate remediation.

## Practical Development

Practical work will use intentionally vulnerable systems, approved training platforms, and explicitly authorised laboratory environments.

Each investigation should document:

- Scope and authorisation.
- Testing objectives.
- Methodology and tools.
- Findings and supporting evidence.
- Risk and potential impact.
- Recommended remediation.
- Limitations and lessons learned.

## Development Standards

All testing must remain within explicitly authorised environments and agreed scope.

Work should prioritise accuracy, reproducibility, responsible disclosure, and clear communication.

## Current Status

Foundational penetration testing knowledge is being established.

Practical exercises and assessments will be documented as learning progresses.
