# Defensive Security

## Purpose

This section documents the development of defensive cybersecurity knowledge and practical skills, with an emphasis on protecting systems, monitoring activity, identifying threats, and investigating security incidents.

The objective is to develop the ability to recognise suspicious behaviour, analyse security evidence, strengthen defensive controls, and contribute to effective incident response.

## Learning Objectives

### 1. Defensive Security Fundamentals
- Understanding the role of defensive security.
- Learning the principles of defence in depth.
- Understanding attack surfaces and security boundaries.
- Exploring preventive, detective, and corrective controls.
- Understanding security monitoring responsibilities.

### 2. Security Monitoring and Log Analysis
- Understanding system and application logs.
- Examining authentication events.
- Identifying unusual login activity.
- Understanding failed and successful authentication patterns.
- Learning how to correlate security events.

### 3. Threat Detection and Investigation
- Understanding indicators of compromise.
- Learning the fundamentals of threat intelligence.
- Identifying suspicious processes and network activity.
- Exploring detection rules and alerting.
- Distinguishing genuine threats from false positives.

### 4. Network and Endpoint Defence
- Understanding firewalls and network filtering.
- Exploring endpoint protection.
- Learning about intrusion detection and prevention systems.
- Understanding system hardening.
- Examining patch and vulnerability management.

### 5. Security Operations
- Understanding Security Operations Centre (SOC) responsibilities.
- Learning the fundamentals of SIEM platforms.
- Exploring alert triage and prioritisation.
- Understanding incident escalation.
- Documenting investigation findings.

### 6. Incident Response
- Understanding incident response stages.
- Learning evidence preservation fundamentals.
- Exploring containment and recovery.
- Understanding post-incident reviews.
- Developing clear incident reports.

### 7. Detection Engineering
- Understanding detection logic.
- Developing basic security detection rules.
- Evaluating detection accuracy.
- Measuring false positives and false negatives.
- Improving detection quality through testing.

## Practical Development

Practical work will use authorised laboratories, simulated incidents, controlled datasets, and systems available for legitimate security training.

Each investigation should document:

- The scenario and investigation objectives.
- Data sources and evidence examined.
- Tools and analytical methods used.
- Findings and supporting evidence.
- Detection decisions and reasoning.
- Limitations and possible improvements.
- Lessons learned.

## Development Standards

Defensive investigations should prioritise accuracy, evidence-based conclusions, repeatability, and appropriate handling of sensitive information.

Detection rules and tools should be tested against both relevant and benign activity to evaluate their effectiveness.

## Current Status

Defensive security foundations are being established.

Practical investigations, detection exercises, and original projects will be documented as learning progresses.
