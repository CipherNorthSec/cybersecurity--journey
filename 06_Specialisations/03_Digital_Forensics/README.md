# Digital Forensics

## Purpose

This section documents the development of digital forensics knowledge and practical skills, with an emphasis on identifying, preserving, examining, and interpreting digital evidence.

The objective is to develop the ability to investigate digital activity systematically, reconstruct events, recognise relevant artefacts, and communicate findings through accurate technical reports.

## Learning Objectives

### 1. Digital Forensics Fundamentals
- Understanding the purpose and scope of digital forensics.
- Learning the principles of evidence handling.
- Understanding evidence integrity and chain of custody.
- Exploring forensic investigation procedures.
- Understanding legal and ethical responsibilities.

### 2. Filesystems and Storage
- Understanding files, directories, and filesystem structures.
- Exploring common filesystem formats.
- Learning about metadata and timestamps.
- Understanding deleted files and data recovery concepts.
- Examining file hashes and integrity verification.

### 3. Operating System Artefacts
- Examining relevant Linux system artefacts.
- Understanding authentication and system logs.
- Exploring user activity records.
- Identifying processes and system activity.
- Understanding how operating systems record events.

### 4. Evidence Acquisition and Preservation
- Understanding forensic imaging.
- Learning about write protection.
- Calculating and verifying cryptographic hashes.
- Preserving original evidence.
- Documenting evidence handling procedures.

### 5. Timeline Reconstruction and Analysis
- Understanding timestamps and event sequencing.
- Correlating information from multiple sources.
- Reconstructing user and system activity.
- Identifying inconsistencies and unusual events.
- Recognising limitations in available evidence.

### 6. Forensic Tools and Techniques
- Exploring command-line forensic utilities.
- Learning the fundamentals of Autopsy.
- Understanding file and metadata analysis.
- Exploring basic memory forensics concepts.
- Developing repeatable examination procedures.

### 7. Reporting and Investigation
- Documenting investigative methods.
- Separating observations from interpretations.
- Supporting conclusions with evidence.
- Explaining uncertainty and limitations.
- Producing clear and reproducible technical reports.

## Practical Development

Practical work will use authorised training environments, controlled datasets, and files specifically provided for forensic examination.

Each investigation should document:

- The investigation scenario and objectives.
- The evidence examined and its source.
- Preservation and integrity checks.
- Tools and methods used.
- Observations and analytical findings.
- Conclusions supported by evidence.
- Limitations and alternative explanations.
- Lessons learned.

## Development Standards

Forensic work should prioritise evidence integrity, repeatability, accurate recordkeeping, and responsible handling of sensitive information.

Original evidence should be preserved wherever possible, and conclusions should never exceed what the available evidence supports.

## Current Status

Digital forensics foundations are being established.

Practical examinations, investigative reports, and original projects will be documented as learning progresses.
