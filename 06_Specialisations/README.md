# Cybersecurity Specialisations

## Purpose

This section documents the exploration and development of practical skills across four major cybersecurity disciplines.

The objective is to build a broad technical foundation before developing deeper expertise through independent study, practical investigations, original projects, and documented assessments.

## Specialisation Areas

### 1. Penetration Testing

Developing the knowledge and practical skills required to assess the security of systems and applications within authorised environments.

Learning areas include:
- Reconnaissance and information gathering.
- Understanding attack surfaces.
- Vulnerability identification and assessment.
- Web application security.
- Security testing methodologies.
- Technical reporting and remediation recommendations.

### 2. Defensive Security

Developing the ability to monitor systems, identify suspicious behaviour, investigate security events, and strengthen defensive controls.

Learning areas include:
- Security monitoring and log analysis.
- Threat detection and investigation.
- Incident response fundamentals.
- Endpoint and network security.
- Security information and event management.
- Detection engineering.

### 3. Digital Forensics

Developing the ability to identify, preserve, examine, and interpret digital evidence.

Learning areas include:
- Digital evidence fundamentals.
- File systems and metadata.
- Evidence preservation and integrity.
- Timeline reconstruction.
- Operating system artefact analysis.
- Forensic documentation and reporting.

### 4. Security Automation

Developing programming and scripting skills to improve the efficiency, consistency, and reliability of cybersecurity workflows.

Learning areas include:
- Python for cybersecurity.
- Log processing and analysis.
- Automated detection rules.
- File integrity monitoring.
- Data extraction and transformation.
- Testing and maintaining security tools.

## Development Approach

Each specialisation will include:

- Structured learning and technical notes.
- Guided and independent practical exercises.
- Knowledge checks and practical assessments.
- Documented investigations.
- Original projects where appropriate.
- Critical evaluation of results and limitations.

## Cross-Disciplinary Development

The four disciplines will not be studied in isolation.

Practical work will explore how they complement one another. For example, network traffic analysis may support defensive monitoring, penetration testing, and forensic investigation.

## Professional Standards

All practical security activities must take place in authorised environments.

Work should prioritise technical accuracy, reproducibility, ethical conduct, clear documentation, and demonstrable understanding.

## Current Status

The four specialisation pathways are being established.

Progress will be documented as foundational knowledge develops and practical work advances.
