## Featured Project

### Project Frank — Account Activity Investigation

**Python | Audit Logs | Timestamp Analysis | Data Validation**

Project Frank is an original Python cybersecurity project that examines synthetic account activity records to identify missing information and reconstruct an account activity timeline.

**Key capabilities:**
- Chronological sorting of timestamped events.
- Structured audit-log analysis.
- Detection of missing expected IP-address information.
- Differentiation between missing information and explicitly recorded removal events.
- Documented forensic findings and project limitations.
